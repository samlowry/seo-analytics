# Brand protection: домены Mostbet из Corsearch

Выгрузки отчёта Websites из Corsearch (zeal.corsearch.com), переведённые в CSV и проверенные
по DNS. Актуальная — `2026-09-28/`.

В каждой папке три файла:

- `all.csv` — все строки, все колонки выгрузки плюс `domain_ascii` (punycode для IDN),
  `dns_status`, `dns_ips`, `dns_note`;
- `resolves.csv` — есть A или AAAA;
- `not-resolving.csv` — всё остальное, причина в `dns_status`.

`dns_status`: `resolves` — есть адрес; `nxdomain` — имени нет; `no_address` — имя есть,
адресов A/AAAA нет; `error` — почти всегда SERVFAIL: домен зарегистрирован, но его NS не
отвечают (битая делегация), изредка таймаут. Выборочная перепроверка ошибок даёт тот же ответ.

«Ресолвится» не значит «сайт работает» — HTTP не проверялся.

### Минус наши домены

`resolves-minus-ours.csv` — `resolves.csv` без наших доменов из
[`our-domains.txt`](our-domains.txt) (469 шт., список от владельца 28.09.2026). Сравнение по
punycode в нижнем регистре, без `www.`: `resolves` 34 328 − 455 наших строк = **33 873**.

`resolves-minus-ours-unique.csv` — то же, одна строка на домен: **33 859**. Дубли в базе
только у кириллических доменов: 14 записаны дважды, юникодом (`мосбэт.рф`) и punycode
(`xn--90avgmg9d.xn--p1ai`), под разными `website_id`. Оставлена строка с заполненным
`infringement_type`, при равенстве — с поздним `crawling_date`; ID второй записи — в колонке
`other_website_ids`. По всей базе таких пар 19.

Из 469 наших: 453 ресолвятся, среди нересолвящихся нет ни одного, 16 в базе Corsearch нет
вовсе — они в `our-domains-not-in-base.txt` (девять из них на `.co.com`).

Сайты не открывались: часть из них может клоачить, на этом этапе ходим только в DNS.

Фильтры в адресе страницы: `interval=exact_dates&start_date=…&end_date=…`, статус —
`taken_down_websites=ONLINE|OFFLINE|PARKED|UNKNOWN`.

## Скан на аффилиатов Mostbet — 28.09.2026

Папка `2026-09-28/affiliate-scan/`. Вход — `resolves-minus-ours-unique.csv`, 33 859 доменов.
Только HTTP с браузерным User-Agent, без браузера и прокси, с одного IP (Европа).

- `affiliate.csv` — **4 261**: на главной есть рефка Mostbet, прямо или через цепочку редиректов;
- `not-affiliate.csv` — **7 467**: открылись, рефки нет;
- `failed.csv` — **22 131**: не открылись или без браузера не решить, причина в `reason`;
- `camoufox-queue.csv` — те же 22 131 в порядке прогона браузером (см. ниже);
- `scan.jsonl.gz` — полный лог: по каждому сайту все внутренние и внешние ссылки с
  источником (`a`, `onclick`, `data-*`, скрипт, base64), кандидаты с причиной выбора,
  цепочки редиректов по каждому проверенному, непроверенные после находки.

**Рефка Mostbet** — `https://<хост>/<4 символа [A-Za-z0-9], хотя бы одна заглавная>`, с
параметрами или без (`?sub1=…`); это форма всех 567 рефок реестра сканера битых ссылок.
Хост должен быть похож на рефочный: из реестра, случайная строка (цифры или почти нет
гласных) или со словом `most`; соцсети, диплинки `onelink.me`, сокращалки — нет. Путь вида
`/News` (заглавная и три строчные) рефкой не считается — в реестре таких нет. Отдельно
считается ссылка на хост с `mostbet` и партнёрским параметром (`pid`, `p`, `promo`, …).

**Порядок на сайт.** Прямая рефка на главной — сразу аффилиат, цепочки не проверяются.
Иначе кандидаты по приоритету: ссылки из скриптов и атрибутов кнопок → внутренние пути вида
`/go/`, `/out/`, `/bonus`, `/reg`, `/app` → внешние ссылки (кроме соцсетей и платформ), до 25.
Каждый — запросами без открытия, до 8 переходов; если шаг отдаёт страницу, ищутся рефка в её
ссылках и `meta refresh`/`location` в коде. Первая найденная рефка останавливает поиск.
**Сам адрес рефки не запрашивается никогда** — иначе накрутится статистика партнёрки.

Как нашлись аффилиаты: внутренний редирект 2 093, прямая ссылка 1 353, ссылка в base64
(`/aHR0cHM6Ly…`) 225, `onclick` 157, внешний редиректор 152, адрес в скрипте 117,
`data-*` 107, редирект самой главной 14.

**Не аффилиаты** — с пометками: `thin_page` 2 699 (заглушка, почти пусто, скриптов нет);
`gate_dead` 217 — есть шлюз вида `/go/`, но он отдаёт ошибку; `gate_other` 1 234 — шлюз ведёт
на чужую партнёрку (`dashplay37.com` 197, `*.top`-редиректоры и т. п.), хост в колонке.
Сайт о Mostbet (≥3 упоминаний) с кликабельными элементами без адреса сюда не попадает —
он в `failed` как `needs_browser_js_buttons`: ссылку ему подставляет скрипт.

**Не открылись**, главное: нужен браузер (ссылку собирает скрипт) 7 105; Cloudflare `403`
3 103; страница рисуется скриптом 2 988; `403` 2 202; капча 1 115; Cloudflare `503` 1 044;
DDoS-Guard 859; проверка Cloudflare 778; таймаут 593.

**Очередь camoufox** (`camoufox-queue.csv`: `domain`, `url`, `reason`, `priority`,
`mostbet_mentions`), `url` — исходный домен, редирект браузер проходит сам:

- 1 — нужен браузер (скрипт, пустая без JS) — 10 093;
- 2 — защита от ботов: Cloudflare, капча, DDoS-Guard — 8 181;
- 3 — ошибка 4xx/5xx, часть — отсечка по стране, тогда прокси — 2 805;
- 4 — сеть: таймаут, отказ, TLS — вероятно, мёртвые — 1 052.

Внутри приоритета — по числу упоминаний Mostbet на главной, по убыванию.


заново (в отчёт идёт последняя запись).
