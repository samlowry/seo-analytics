# Классы сайтов brand scan (срез 30.09.2026)

Файл: `classified.csv` — все 33 859 доменов базы Corsearch минус наши, одна категория на сайт и теги.
Пересобрать (без сети):

```
uv run --with selectolax --with aiohttp python tools/brand-site-features.py brand-protection/2026-09-28/brand-scan
uv run --with selectolax --with aiohttp python tools/brand-classify.py brand-protection/2026-09-28
python3 tools/brand-review-page.py brand-protection/2026-09-28/brand-scan/review
```

Источники: `groups.csv` и `destinations.csv` (brand-scan, 22 тыс. сайтов с пройденными ссылками),
`affiliate-scan/` (11,7 тыс., с цепочками шлюзов), признаки из сохранённого HTML (`site-features.jsonl.gz`).

## Категории

Нарушители, главная цель:
- `mono_other` — монобренд Mostbet, аффилиатские ссылки только на чужие бренды;
- `mono_mixed` — монобренд Mostbet, ссылки и на Mostbet, и на чужих (часто ротация одной ссылки).

Монобренд Mostbet, остальное:
- `mono_xlink` — чужой рекламы нет, простые ссылки на сайты других брендов;
- `mono_unresolved` — кнопки ведут на свой шлюз или трекер, до получателя никто не дошёл; здесь могут
  прятаться `mono_other`, нужен сетевой догон с RS-IP;
- `mono_mostbet` — реклама только Mostbet;
- `mono_no_ads` — аффилиатских ссылок нет.

Бренд в домене — нарушитель при любом содержимом (правило владельца, 30.09):
- `bait` — Mostbet в домене или title, внутри чужое казино или чужой бренд;
- `discredit` — Mostbet в домене, содержимое вообще не про гэмблинг (магазин, наркошоп) — дискредитация бренда;
- `redirect_other` — главная сразу уводит на чужую рефку.

Прочие типы: `mirror` (официальное зеркало),
`redirect_ref` / `redirect_other` (главная сразу уводит на рефку Mostbet / чужую), `multibrand`
(гэмблинг-аффилиат не про Mostbet), `article` (статейник, Mostbet в постах), `hacked` (чужая тема,
Mostbet в ссылках, часто скрытых), `other_gambling`, `unrelated`, `unclear`.

Статусы: `stub` (пустая страница), `parked`, `dead`, `not_shown` (защита, ошибка, гео-блок).

Теги: `brand_in_domain`, `moved` (главная переехала на другой хост), `ads_unverified` (есть ссылки,
не пройденные до конца), `rotating_ads` (разные прогоны дали разную рекламу), `search_referrer_js`
(скрипт реагирует на заход из поиска), `apk`, `platform` (blogspot, wix и т. п.), `our_ref`, `no_html`.

Реклама = ссылка с кодом партнёра (параметры `pid`, `tag`, `affiliateCode`, `sub1`…), проход через
трекер (промежуточный хост) или прямая ссылка на чужого оператора (1win-mx.mx, 22bet4u.com — правило
владельца). Чужой трекер засчитывается, даже если сейчас не открывается. Переезд домена, APK, цепочка
переездов по доменам со словом mostbet без кода — не реклама. `mono_xlink` — только простые ссылки на
чужие дорвеи, не на операторов.

`corsearch-false-positives.csv` — сайты без малейшего следа бренда (ни в домене, ни на странице, ни в
ссылках): Corsearch собрал их по ошибке, список для их вайтлиста.

## Проверка

Три круга по 10 сайтов на категорию (равномерно по списку, каждый сайт читали по сохранённому HTML) плюс
ручная разметка владельца 30.09 (`review/round1/`, `review/round2/`, `review/verdicts-r3-*.json`).
После правок классификация сходится с проверяющим на 165 из 200 (второй круг) и 74 из 90 (третий);
`mono_other` — 10 из 10 во всех трёх кругах. `review/review.html` — расхождения третьего круга.

## Сетевые проходы 30.09 (с Yettel RS)

- `--mode http` по 11,7 тыс. сайтов affiliate-scan: полный проход ссылок, как у остальных 22 тыс.;
- `--mode gates` (`gates-scan.jsonl.gz`): адреса шлюзов и трекеров из сохранённого HTML, HTTP;
- `--mode browser` по 1 600 «получатель неизвестен» с кликами (`run-browser-unresolved.log`).
Остались `mono_unresolved` — 818: браузер и HTTP не дошли до получателя (мёртвые трекеры, кнопки без адреса).

## «Не показались» (`not_shown`)

Ручная проверка владельца 01.10 (`review/not-shown.html`): по 10 случайных на `403`, `503`, Cloudflare/DDoS-Guard,
`404` — ни один из 38 отмеченных не открылся. Ночной браузерный проход 29–30.09 дал то же. Класс держится
отдельно от `dead`: сервер отвечает, домен (9 207 из 10 237 — с Mostbet в имени) может ожить; перепроверять
HTTP-проходом раз в несколько недель.

## Клоака: заход из Google и Googlebot (01.10)

`brand-scan.py --mode http --as google-mobile|googlebot` по всем 10 237 «не показавшимся» (логи
`http-scan-<as>.jsonl.gz`, отчёты `groups-<as>.csv`, HTML `<домен>.http-<as>.html.gz`). Сайт, скрытый от
обычного посетителя, классифицируется по тому, что видит пришедший из Google (или Googlebot), тег `cloaked:<as>`.
Итог: 6 911 из 10 237 — клоака, а не мёртвые. 2 537 из них уводят мобильного посетителя из Google на одну рефку
Mostbet `gvmuaimb.com/vKrs` → `pid=229671` (`redirect_ref`); 2 355 показывают Googlebot монобренд-страницу, куда
ведут кнопки — неизвестно (`mono_unresolved`); 64 — нарушители. В `not_shown` осталось 3 326.

## Без браузера: мобильный, заход из Google, внутренние страницы, скрипты, PWA (01.10)

- `--as mobile` и `--as google-mobile` по 16 451 живому сайту — ещё два снимка во времени; реклама из них
  объединяется с десктопной. Чужая реклама только у посетителя из Google — тег `ads_search_only`
  (283), только в мобильной версии — `ads_mobile_only` (142).
- `--mode deep` (`tools/brand-deep-queue.py` → `deep-queue.csv`, лог `deep-scan.jsonl.gz`): до 4 внутренних
  страниц (посты со словом Mostbet, регистрация, приложение, бонусы) и до 6 собственных скриптов сайта;
  найденные там ссылки проходятся как ссылки главной. 10 731 сайт.
- PWA: тег `pwa` (170); оффер из `window.appDataConfigs.url` пройден в `gates-scan` (17 лендингов:
  8 → Mostbet, в основном `pid=432659`). У шаблона `paso1` конфиг приходит с сервера после загрузки — без
  браузера не достать.
- Ссылка на соседний домен сети со словом mostbet, который сам уводит на парковку или никуда, не считается
  рекламой ссылающегося сайта.
