# Нарушители Mostbet по классам, уверенность от 90 %

Срез 13.10.2026. В каждом классе — страница с карточками сайтов (HTML), она же в PDF (`tools/brand-group-pdf.py`), она же в Markdown для импорта в Google Docs и таблица с теми же полями (CSV). Взяты нарушители с уверенностью от 90 %: у сайтов, проверенных агентом, — вердикт «нарушитель» с уверенностью проверяющего от 90 %, у непроверенных — шкала «уверенность в нарушении» от 90. Всего 2 537 доменов. Markdown длиннее 900 000 символов разрезан на части: в один Google Doc влезает около 1 млн.
