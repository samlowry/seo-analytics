# Брейншторм по mostbet.com — вводная для новой сессии

Этот файл существует потому, что Agent Teams включается только при старте сессии.
После рестарта контекст прошлой переписки не наследуется — вся вводная здесь.

## Что уже сделано

Полная фактура: **`mostbet-redirect-scheme.md`** в корне репозитория. Прочитать
целиком до начала обсуждения. Там замеры с двух точек (US и RS), декомпиляция
редирект-скрипта и сводка по индексации всех доменов.

## Краткая выжимка

Механика: `mostbet.com` отдаёт пустой SPA-шелл 9.5 KB → скрипт дёргает
`/api/v3/common/redirect` → сервер отвечает `{"redirect":true,"domain":"..."}` →
скрипт делает `window.location.href = ...`. **HTTP-редиректов (30X) нет ни одного.**

Ключевое для обсуждения:

1. **Апекс — самый сильный URL проекта — держит нулевой контент.** Без JS там
   только `<title>`, meta description и пустой `<div id="root">`.
2. **`canonical` отсутствует на апексе полностью.** У `guidebook.mostbet.com` он есть.
3. **hreflang описывает несуществующую конструкцию:** 21 альтернат, среди
   которых нет ни одного реального адресата редиректа. `x-default` уводит на
   посторонний домен `mostbett.bet`.
4. **Клоакинга нет** — по User-Agent контент не различается, хеши совпадают.
   Единственная переменная — исполняется JS или нет.
5. **Закрыты от сканирования только одноразовые зеркала** (`Disallow: /`).
   `guidebook.mostbet.com`, `mostbett.bet`, `mostbet.bet` — открыты.
6. **США закрыты на эдже:** апекс и его API отдают `204`, зеркало — `451`.

## Главное, что нельзя упустить

Со стороны картина выглядела как продуманная трёхслойная архитектура. **Это не так.**
По словам владельца проекта, нынешний пустой шелл выкатили примерно за **3–5 недель**
до замера, после чего **сайт выпал из индекса**. `guidebook.mostbet.com` не назначали
контентным слоём — он просто единственный уцелел в выдаче.

Это **регрессия релиза, а не осознанный размен.** Обсуждение должно исходить из
этого, иначе половина выводов уедет не туда.

## Открытые вопросы (не проверено)

- Меняется ли выдаваемый домен от страны к стране — замер был только из Сербии (RS → `8unx689.com`).
- `mostkaei.com` — второй домен в гейте редиректа, содержимое неизвестно.
- Как система ведёт себя с настоящим IP Googlebot, а не с подменённым User-Agent.
- Ранжируется ли guidebook по коммерческим запросам или только по брендовым.
- Точная дата регрессии — Wayback из окружения замера недоступен.

## Предлагаемый состав команды

4–5 тиммейтов с намеренно конфликтующими интересами, чтобы спор был настоящий,
а не хор согласных:

| роль | за что топит | с кем конфликтует |
|---|---|---|
| **SEO-архитектор** | вернуть контент на апекс, канонизация, честный hreflang | с антиблоком |
| **Инфраструктурщик-антиблок** | живучесть под блокировками, одноразовые домены | с SEO по всем пунктам |
| **Продуктовый / UX** | скорость входа, чтобы юзер не видел пустой экран и редирект | с обоими |
| **Риск и комплаенс** | закрытые рынки, юрисдикции, чтобы не словить 451 там, где не надо | с продуктовым |
| **Адвокат дьявола** | оспаривать любой консенсус, искать, где мы приняли догадку за факт | со всеми |

Задача — спорить между собой напрямую и опровергать версии друг друга, а не
отчитываться лиду по очереди.
